# v0 적용 후 확인할 항목

승인한 기본안을 실제 앱에 적용했다. 아래 사용감과 창 내 동작 항목은 실제 앱에서 확인할 사항이며, 자동 검사 통과와 구분한다.

## 먼저 볼 사용감

| 우선순위 | 확인할 부분 | 현재 적용값과 판단 기준 |
| --- | --- | --- |
| 1 | 자막 문장이 편하게 읽히는가 | 편집 글자는 15px, 원문 단어는 12px, 시간은 고정 폭 글꼴이다. 파형보다 실제 수정 문장이 먼저 읽히는지 확인한다. |
| 2 | 도구 위치를 쉽게 찾는가 | 프로젝트 저장은 첫 줄, SRT 저장은 둘째 줄이다. 다른 이름으로 저장은 각 저장 버튼 옆 ⌄ 메뉴에 있다. |
| 3 | 한 화면의 자막 수가 적당한가 | 카드에는 시간·단어 파형·편집 문장·조작을 표시한다. 기존 샘플 영상으로 여백과 정보량을 확인한다. |
| 4 | 원하는 크기로 영상과 자막을 볼 수 있는가 | 기본 영상 비율은 58%이며 기존 비율 저장을 따른다. 최소 창과 패널을 좁힌 상태에서 조작이 겹치지 않는지 확인한다. |

원하는 조정이 있으면 글자 크기·카드 여백·도구 배치 중 어떤 부분인지 알려주면 된다. 추가 기능을 정하기 위한 승인 단계는 아니다.

## 실제 앱에서 확인할 동작

| 확인 순서 | 조작 | 기대 결과 |
| --- | --- | --- |
| 1 | 영상 열기 또는 기존 프로젝트 열기 | 실제 영상 이름·해상도·길이가 표시되고, 빈 화면 안내가 작업 화면으로 바뀐다. 프로젝트의 영상·자막·파형·재생 위치가 복원된다. |
| 2 | 재생·일시정지, ±1초, 탐색 막대, 속도 조절 | 영상과 밀리초 단위 시간이 함께 변한다. 재생 위치 따라가기가 켜져 있으면 현재 자막이 따라온다. |
| 3 | 자막 문장 수정 후 실행 취소·다시 실행 | 영상 자막이 수정되며 단어 파형과 시간은 보존된다. 변경 전후 문장을 되돌릴 수 있다. |
| 4 | 단어 경계 드래그 또는 경계에서 방향키 | 단어 시간이 이웃을 넘지 않고 조절된다. 방향키는 0.01초, Shift+방향키는 0.1초 단위이며 영상의 1초 탐색과 충돌하지 않는다. |
| 5 | 단어에 마우스 또는 키보드 포커스를 두고 분할, 카드에서 합치기·삭제 | 기존 편집 동작을 수행하며 실행 취소로 복원할 수 있다. |
| 6 | 프로젝트 저장 → 문장 수정 → 다시 저장 → 프로젝트 다시 열기 | 저장 상태 문구가 바뀌며, 최종 편집 내용·파형·재생 설정이 복원된다. 저장 버튼 옆 메뉴로 새 프로젝트 파일도 만들 수 있다. |
| 7 | SRT 불러오기·저장과 영상 내보내기 | 기존 데이터 흐름을 사용한다. 1초 이하 자막 간격 보정이 표시 시간·SRT·영상에 유지된다. |
| 8 | 자막 생성·길이·사전·내보내기 설정창에서 Tab, Shift+Tab, Escape | 포커스가 창 안에서 이동하고 Escape로 닫힌다. 닫은 후 원래 조작으로 포커스가 돌아간다. 작은 창에서는 설정 내용만 스크롤된다. |
| 9 | 영상과 자막 사이 분할선 드래그·방향키·더블클릭 | 기존 조절 범위·초기화와 비율 저장이 유지된다. 좁은 영상 패널에서도 재생 시간·버튼·속도 조절이 겹치지 않는다. |
| 10 | 긴 영상이나 자막이 많은 프로젝트 열기·스크롤 | 기존 구간 스트리밍·가상 스크롤·화면 근처 파형 렌더링을 유지한다. 드래그 안내가 영상·도구 전체를 다시 그리게 만들지 않도록 분리했다. |

## 기술 점검

- TypeScript 검사: 통과.
- 프런트엔드 테스트: 75개 통과. 시간 표시의 밀리초·분/시간 경계 반올림 케이스 포함.
- 디자인/React 코드 점검: 기존 팔레트와 로컬 아이콘 유지, 외부 폰트·추가 UI 라이브러리 없음, 전체 store 구독 축소, 모달 및 버튼의 focus·접근성 이름 보완.
- 최종 빌드: Vite 웹 빌드, Rust 최적화 릴리스 빌드, Windows 포터블 ZIP 생성 통과.
- 실행 파일: src-tauri/target/release/sub-sync.exe. 배포 파일: src-tauri/target/release/sub-sync-portable.zip.
- 실제 네이티브 창의 시각·입력 확인: 미실행. 위 동작 표는 수동 확인 목록이다.

프로젝트 포맷·Rust 백엔드·Whisper·자막 간격 보정 로직은 이번 UI 변경에서 수정하지 않았다.

# Sub Sync UI/UX 개선안

상태: 사용자 디자인 방향 및 v0 적용 승인 완료. 기본안의 화면 구성과 실제 편집 기능 연결을 앱에 반영했다. 다음 사용자 확인 항목은 UI_CHECKLIST.md에 정리한다.

## 목적과 범위

긴 영상을 확인하며 자막의 문장과 타이밍을 반복 수정하는 데 집중할 수 있는 편집 화면을 만든다. 기존 화면을 발전시키는 **Redesign · Preserve** 방식으로 진행한다.

- 유지: 어두운 작업 화면, 청록색 강조, 영상과 자막의 좌우 배치, 단어별 파형, 한국어 조작 문구.
- 개선: 상단 버튼의 우선순위, 프로젝트 저장 상태, 자막 원문과 편집 문장의 구분, 재생 조작, 초기 안내, 대화상자 접근성.
- 정리: 동일한 강도의 버튼 나열, 약한 편집 영역 구분, 마우스를 올려야 발견할 수 있는 조작.
- 보호: 프로젝트 포맷, 저장·불러오기 동작, 자막 시간 데이터, 작은 간격 보정, 단축키, 패널 조절과 비율 저장, 가상 스크롤, 영상 스트리밍.

## 현재 화면 분석

분석 근거는 실제 React/CSS 소스이며, 화면을 실행하여 확인한 결과는 아니다.

| 영역 | 현재 상태 | 개선 방향 |
| --- | --- | --- |
| 상단 도구 모음 | 프로젝트·영상·SRT·편집 버튼이 하나의 flex-wrap 영역에 배치된다. 파일명이 오른쪽에 작게 나타난다. | 프로젝트 정보와 파일 조작을 위쪽에, 자막 작업 도구를 아래쪽에 모아 위치를 안정시킨다. |
| 영상 | 검은 배경에 영상과 하단 재생 막대가 있다. 빈 화면에는 파일 열기 버튼 하나가 표시된다. | 영상 이름과 실제 메타데이터를 보여주고, 시작과 이어서 작업하기를 안내한다. |
| 재생 | 재생 버튼, 시간, 속도를 제공한다. 탐색 막대에는 접근성 이름이 없다. | 시간 표시와 조작의 정렬을 맞추고, 탐색 이름과 단축키 안내를 제공한다. |
| 자막 목록 | 카드마다 파형 단어 칩과 청록색 textarea가 이어진다. 시작 시각과 지속 시간만 표시된다. | 시작·종료 시각을 명확히 보여주고, 편집 문장을 더 쉽게 읽을 수 있도록 대비를 높인다. |
| 편집 조작 | 합치기·삭제는 hover나 내부 focus 시 노출되고, 단어 분할은 hover로만 나타난다. | 키보드로 조작을 발견하고 실행할 수 있도록 focus 표시와 접근성 이름을 보완한다. |
| 대화상자 | 설정들이 하나의 목록으로 나열된다. role=dialog는 있지만 focus 이동·복원·가두기와 Escape 처리가 없다. | 설정을 목적별로 묶고, 모달 focus와 닫기 동작을 보완한다. |
| 상태 피드백 | 프로젝트 변경은 파일명 뒤 별표, 작업 진행은 막대, 메시지는 닫을 수 있는 버튼으로 표시된다. | 기존 데이터가 의미하는 변경 상태를 명시적으로 보여주고, 진행과 메시지에 접근성 의미를 제공한다. |

현재 시각 문법은 14px 기본 글꼴, 6/10/12px 모서리, 6~16px 간격, 거의 없는 그림자와 상태 전환으로 이루어져 있다. 이를 유지하며 역할별 토큰으로 정리한다.

## Design Read

- Artifact: 로컬 영상·자막 편집 작업 화면.
- Audience: Whisper 결과를 검토하고 자막 문장과 타이밍을 수정하는 사용자.
- Visual language: 차분한 전문 영상 편집 도구. 고정된 도구 영역과 읽기 쉬운 시간 정보가 중심이다.
- Mode: Redesign · Preserve.
- Constraints: 기존 Tauri/React 구조, 한국어 UI, 최소 창 1100×700, 큰 영상과 많은 자막, 오프라인 사용.

| 조절 축 | 값 | 실제 설계에 미치는 영향 |
| --- | --- | --- |
| Visual variance | 2/10 | 좌우 작업 구조와 카드 목록을 유지하고 도구의 묶음만 정돈한다. |
| Motion intensity | 2/10 | hover·focus 등 상태 피드백만 짧게 전환한다. 재생 중 반복 장식 효과를 넣지 않는다. |
| Information density | 8/10 | 넓은 홍보 영역 없이 영상과 여러 자막이 동시에 보이도록 높이와 간격을 절제한다. |
| Asset dependence | 1/10 | 사용자 영상, 실제 파형과 기존 앱 아이콘을 활용한다. 외부 이미지가 필요하지 않다. |
| Brand fidelity | 9/10 | 기존 색상, 글꼴과 조작 명칭을 기반으로 한다. |

## 시스템 선택의 근거

- 화면의 역할: 콘텐츠를 소개하는 페이지가 아니라 반복 편집을 수행하는 작업대다. 영상과 현재 자막이 가장 먼저 읽혀야 한다.
- 시청 거리: 노트북·데스크톱 거리다. 기본 조작 글자는 14px, 편집 문장은 15~16px, 시간 숫자는 고정 폭으로 설계한다.
- 시각적 온도: 차분하고 정밀하다. 청록색은 주요 작업과 현재 선택을 알려준다.
- 수용량: 1600×950을 기준으로 설계하고 1100×700에서도 파일명, 버튼, 카드 조작이 겹치지 않도록 묶음과 줄바꿈을 조절한다. 자막 패널의 최소 폭 400px을 고려한다.

## Design Decisions

- Anchor: 기존 Sub Sync 시각 체계를 발전시키는 자체 시스템. 외부 제품의 디자인이나 자산을 모방하지 않는다.
- Palette: 배경 #14161a, 패널 #1c1f24, 입력·hover #262a31, 경계 #363b44, 본문 #e8eaed, 보조 글자 #9aa0aa, 강조 #29b6f6, 파형 #4fc3f7. 선택 배경은 강조색에서 낮은 불투명도로 파생한다.
- Typography: 현재 Pretendard → Malgun Gothic → Segoe UI 순서를 유지한다. 시간 정보는 Consolas → monospace와 tabular-nums를 사용한다. 외부 폰트를 내려받지 않는다.
- Type scale: 조작·본문 14px, 편집 문장 15~16px, 패널 제목 15px, 대화상자 제목 20px, 보조 설명 12~13px. 파일명과 실제 편집 문장이 장식 제목보다 우선한다.
- Spacing: 4px 기준, 4/8/12/16/24px. 패널 여백 16px, 카드 사이 12px, 버튼 높이 약 32~36px.
- Radius: 버튼·입력 6px, 자막 카드 10px, 대화상자 12px. 역할과 무관한 알약 모양을 추가하지 않는다.
- Shadow: 기본 작업 면에는 그림자를 쓰지 않는다. 메뉴·대화상자만 0 12px 36px rgba(0,0,0,.35)를 사용한다.
- Motion: 색상·경계 전환 120ms ease-out. prefers-reduced-motion에서는 전환을 줄인다. 진행 막대의 불확정 상태는 기존 의미를 유지한다.
- States: hover, focus-visible, pressed, disabled, empty, loading, error를 실제 동작에 맞춰 표현한다. 상태는 색상과 함께 문구·테두리로 전달한다.

## 제안하는 화면 구성

1. **프로젝트 바**: 기존 아이콘과 앱 이름, 현재 파일명, 변경 상태를 왼쪽에 배치한다. 프로젝트 열기·저장과 영상 내보내기를 안정된 위치에 둔다. 다른 이름으로 저장 기능도 유지한다.
2. **작업 도구 모음**: 영상 열기 → 자막 생성 → 자막 길이·단어 사전 흐름을 한 묶음으로 만든다. SRT 불러오기·저장과 실행 취소·다시 실행은 별도 묶음으로 정렬한다. 자주 쓰지 않는 저장 옵션은 명확한 보조 메뉴로 제공할 수 있다.
3. **영상 패널**: 실제 영상 이름·길이·해상도를 간결한 헤더에 표시한다. 영상과 자막 미리보기의 비율 계산을 보존하고, 하단에 재생·시간 탐색·속도를 정렬한다.
4. **자막 패널**: 자막 수와 재생 위치 따라가기를 상단에 고정한다. 현재 자막은 테두리와 상태로 표시하고, 각 카드의 시간 → 단어 파형 → 편집 문장 순서를 유지하며 시각적 강도를 조정한다.
5. **빈 화면**: 영상 열기와 기존 프로젝트 이어서 작업하기를 안내한다. 영상이 열린 뒤에는 자막 생성이나 SRT 불러오기를 다음 행동으로 안내한다.
6. **설정과 피드백**: Whisper 설정과 자막 분할 설정을 시각적으로 구분한다. 모달의 Escape·focus 복원, 작업 진행률, 메시지 전달을 보완한다.

새 화면이나 기능 페이지를 추가하지 않는다. 사용자의 실제 파일명·길이·자막 수를 사용하며 예시 통계를 넣지 않는다.

## 보호할 동작과 구현 경계

- 프로젝트 저장·자동 저장·불러오기와 SRT 입출력은 기존 store/API를 사용한다.
- 프로젝트와 파형 데이터, 단어 시간값, undo/redo 기록의 처리 규칙은 바꾸지 않는다.
- Ctrl+O, Ctrl+S, Ctrl+Shift+S, SRT 저장 단축키, 실행 취소·다시 실행, Space·방향키 동작을 보존한다.
- 텍스트 입력·설정창·패널 너비 조절 중에는 전역 재생 단축키가 충돌하지 않도록 한다.
- 분할선의 드래그·키보드 조절·초기화·비율 저장 키를 유지한다.
- 가상 스크롤, 화면 근처 파형만 그리는 방식, 재생 상태 구독 범위를 유지한다.
- 기존 SVG 원본은 src-tauri/icons/source.svg이다. UI에서 사용할 경우 로컬 자산으로 참조하며 다시 그리지 않는다.
- 외부 UI 프레임워크나 애니메이션 패키지를 추가하지 않는다.

가장 큰 변화는 도구의 재배치다. 실제 편집 동작을 담은 store/player/shared 모듈과 시각 구성 변경을 분리해 회귀 위험을 줄인다.

## v0 확인 방법

- docs/ui-v0.html을 브라우저에서 연다. CSS/JS와 아이콘은 로컬 파일이며 서버나 인터넷 연결이 필요하지 않다.
- 작업 중 로컬 미리보기 주소: http://127.0.0.1:1421/ui-v0.html. 서버를 다시 띄우려면 저장소에서 `python -m http.server 1421 --bind 127.0.0.1 --directory docs`를 실행한다.
- 기본 화면은 제공받은 SRT 3개 문장으로 구성했다. 영상과 파형은 자리 표시자다.
- 카드 번호·시간 탐색·문장 수정·실행 취소·다시 실행·분할선 드래그와 키보드 조절을 체험할 수 있다.
- 오른쪽 아래 Tweaks에서 균형·문장 중심·타이밍 중심의 세 구성을 비교하고, 목록 간격과 빈 화면을 전환한다.
- 이 HTML 파일은 이전 확인용 시안이다. 실제 앱의 최신 화면과 기능은 src/renderer에 반영되어 있으며, 시안의 자리 표시자와 가상 동작은 앱에 포함되지 않는다.

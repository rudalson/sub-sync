UI/UX 첫 시안

승인한 디자인 방향을 확인하기 위한 화면입니다.

  • 어두운 배경, 청록색 강조, 좌우 편집 구조를 유지합니다.
  • 기존 앱 아이콘과 제공해주신 SRT 문장을 사용했습니다.
  • 영상·단어별 시간·파형은 실제 데이터 연결 전 자리 표시자입니다.
  • 카드 번호, 시간 탐색, 문장 수정, 실행 취소·다시 실행, 패널 너비 조절을 체험할 수 있습니다.
  • 파일 열기·저장과 Whisper 실행은 화면 확인 후 실제 앱에 연결합니다.
  • Tweaks는 시안 비교용이며, 최종 앱에 상시 노출할 도구가 아닙니다.
